# Publication Flip-Card Grid — Design

**Date:** 2026-06-22
**Status:** Approved design, ready for implementation plan
**Branch:** `site-uplift` (unmerged; folds into the in-flight work)
**Supersedes:** the 40:60 `.pubcard` design (`2026-06-21-publication-card-redesign-design.md`) — only the publication card markup/CSS changes; venue derivation, buckets, build pipeline, and `publications.json` structure carry over.

## Problem

The Publications section should present Books / Papers / Digital as a grid of portrait
**flip cards**: front shows the cover image (or, for papers with no cover, the title),
clicking the card flips it to reveal the details, and a bottom link strip opens the venue
(Amazon / arXiv / SSRN / Ko-fi) in a new tab. The articles list is unchanged.

## Decisions (locked)

- **Grid:** each bucket (Books · Papers · Digital) is a responsive grid — 3-up desktop,
  2-up tablet (≤900px), 1-up mobile (≤560px). Cards are portrait with a fixed aspect so
  the 3D flip has a stable height.
- **Front always carries the title.** Image cards (Books cover, Ko-fi thumbnail) show the
  image with a **title caption**; Papers (no image) show a **venue-tinted title panel**.
- **Back = description + meta only** (NO title — it is on the front already).
  - Book meta: the `meta` string (e.g. "Kindle · 134 pages · May 26, 2026").
  - Paper meta: authors (self bolded) + display date.
  - Digital meta: none (the one-line `desc` is the body).
- **Bottom link strip on both faces:** a venue-labelled external link (`Amazon ↗` /
  `arXiv ↗` / `SSRN ↗` / `Ko-fi ↗`), venue-colored, `target="_blank" rel="noopener"`.
  Clicking it does NOT flip (the handler ignores clicks originating in the link strip).
- **Flip interaction:** the main face is an accessible toggle **button** (`aria-expanded`,
  Enter/Space + click); clicking again flips back. One delegated JS handler in the template.
- **Reduced motion:** `@media (prefers-reduced-motion: reduce)` swaps faces instantly
  (no 3D rotate).
- **Add SSRN paper** (DOI `10.2139/ssrn.6071412`): *The Great Recalibration: The 2026 Pivot
  from Generalist Wrappers to Sovereign Application Layers and Industrialized Services*,
  Anuj Sadani, 2026. Papers bucket → 3; the "Papers" pillar count → 3.
- **Renderer tolerates a year-only paper date** (SSRN carries only `2026`).

## Architecture

### Files

```
data/publications.json  ← add the SSRN paper (3rd entry in papers[]); papers carry a
                           `dateDisplay` string (e.g. "May 13, 2026", "2026") for display,
                           so year-only dates render without a parser.
build.js                ← renderPublicationCard → renderFlipCard(item, type); helpers for
                           the front face (image+caption vs title panel), back face
                           (desc + meta), and the venue link strip. renderPublications
                           keeps its contract (3 labeled buckets) but wraps each bucket's
                           cards in a grid container.
assets/site.css         ← replace the .pubcard rules with the flip-card grid + 3D flip
                           system + venue colors + reduced-motion fallback.
templates/index.template.html ← add a small delegated flip-toggle <script>.
index.html              ← regenerated by `node build.js`.
test/*                  ← update build.test.js + publications-data.test.js for the new markup.
```

### Card markup (per item)

```html
<div class="flipcard venue-<key>">
  <div class="flipcard-inner">
    <!-- FRONT -->
    <div class="flipcard-face flipcard-front">
      <button class="flipcard-toggle" type="button" aria-expanded="false"
              aria-label="Show details for <title>">
        <!-- image card: --> <img class="flipcard-cover" src="..." alt="<title> cover">
                             <span class="flipcard-caption"><title></span>
        <!-- paper card: --> <span class="flipcard-panel-venue">arXiv</span>
                             <span class="flipcard-paneltitle"><title></span>
      </button>
      <a class="flipcard-link" href="<url>" target="_blank" rel="noopener"><venue> ↗</a>
    </div>
    <!-- BACK -->
    <div class="flipcard-face flipcard-back">
      <button class="flipcard-toggle" type="button" aria-expanded="false"
              aria-label="Hide details">
        <span class="flipcard-desc"><description></span>
        <span class="flipcard-meta"><meta></span>
      </button>
      <a class="flipcard-link" href="<url>" target="_blank" rel="noopener"><venue> ↗</a>
    </div>
  </div>
</div>
```

- `.flipcard.is-flipped .flipcard-inner { transform: rotateY(180deg); }` drives the flip;
  `.flipcard-back` is pre-rotated 180°, `backface-visibility: hidden` on both faces.
- The two `.flipcard-toggle` buttons keep `aria-expanded` in sync (JS sets both).

### Per-type front / back / venue mapping

| Type | front face | back face | venue (link + color) |
|------|-----------|-----------|----------------------|
| Book | `cover` image + title caption | `desc` + `meta` | Amazon → `--accent*` |
| Paper | venue wordmark + title panel (no image) | authors + `dateDisplay` | arXiv → `--red*`, SSRN → `--blue*` |
| Digital | `image` thumbnail + title caption | `desc` | Ko-fi → `--accent*` |

### Render interface (build.js)

- `venueFor(type, item) -> { key, label }` — unchanged from current (`amazon` / `arxiv` /
  `ssrn` / `kofi`).
- `renderFlipCard(item, type) -> string` — emits the `.flipcard` markup above, choosing
  image-caption vs title-panel for the front and the type-specific back/meta.
- `renderPublications(pubs) -> string` — unchanged buckets, but each bucket's items are
  wrapped: `<div class="pub-bucket-label">…</div><div class="flip-grid"> …cards… </div>`.
- Paper meta/back date uses `item.dateDisplay` (string) directly — no `formatDate` parse,
  so `"2026"` is fine.

### Flip-toggle script (template)

One delegated listener, added to the existing `<script>` region in
`templates/index.template.html`:

- On `click` within `#research`: if the target is inside a `.flipcard-link`, do nothing
  (let the link open). If inside a `.flipcard-toggle`, toggle `is-flipped` on the closest
  `.flipcard` and set `aria-expanded` on both its toggles.
- Buttons are natively keyboard-activatable (Enter/Space), so no extra key handling needed.

## Testing

- `test/build.test.js`:
  - `renderFlipCard` book → `.flipcard`, `.flipcard-cover`, `.flipcard-caption` with title,
    back `.flipcard-desc` + `.flipcard-meta`, link `Amazon ↗`, class `venue-amazon`.
  - paper → no `.flipcard-cover`; has `.flipcard-paneltitle` + `.flipcard-panel-venue`
    (`arXiv`); back shows authors; link `arXiv ↗`; `venue-arxiv`.
  - digital → `.flipcard-cover` + caption; back `.flipcard-desc`; link `Ko-fi ↗`;
    `venue-kofi`.
  - both `.flipcard-toggle` buttons carry `aria-expanded="false"`.
- `test/publications-data.test.js`:
  - papers length 3 (SSRN present, URL contains `ssrn` / `6071412`).
  - `renderPublications` emits a `.flip-grid` per bucket and `.flipcard` count ==
    books+papers+digital.
- Existing suite stays green; `node build.js` idempotent; article-list equivalence intact.

## Out of scope (YAGNI)

- og:image / social-unfurl (separate later cycle).
- Real brand logo SVGs (venue is a text wordmark).
- Animating anything beyond the single flip; carousel; lazy-loading thumbnails.
- Touching article rows or article pages.

## Success criteria

- Each bucket renders as a 3-up (responsive) grid of portrait flip cards.
- Front shows cover+title caption (books/digital) or venue title panel (papers); back
  shows description + meta with no repeated title.
- Clicking a card flips it (and back); the bottom venue link opens in a new tab without
  flipping; keyboard (Enter/Space) flips; reduced-motion swaps without rotation.
- SSRN paper present; Papers pillar count = 3.
- `node build.js` regenerates `index.html`; full suite green; build idempotent; light mode
  renders correctly (homepage is light-only).
