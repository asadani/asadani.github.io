# Publication Card Redesign — Unified 40:60 Split Card with Venue Badge

**Date:** 2026-06-21
**Status:** Approved design, ready for implementation plan
**Branch:** `site-uplift` (folds into the in-flight site uplift; not yet merged)
**Depends on:** `2026-06-21-site-uplift-design.md` (the build pipeline + `publications.json` this builds on)

## Problem

The Publications section renders three visually inconsistent card types: `.book-card`
and `.store-card` have cover art, but `.pub-card` (papers) is text-only and reads as the
bare "poor cousin." The goal is one premium, consistent card — inspired by testimonial
cards (text + a round avatar/label anchored at the bottom) — that gives every publication
a thumbnail/visual and a venue identity.

## Decisions (locked)

- **One unified card** `.pubcard` replaces `.book-card`, `.pub-card`, `.store-card`.
- **Layout:** 40:60 horizontal split — media zone left (40%), content right (60%).
- **Papers have no image** → their media zone is a tinted **venue panel** (wordmark +
  category), not a cover.
- **Venue badge:** a small **text wordmark chip** (the venue name as text, e.g. `arXiv`,
  `SSRN`, `Ko-fi`, `Amazon`) anchored in a foot row — NOT a monogram circle. Pure CSS
  pill consistent with the site's existing badges, colored per venue via variables so
  dark mode works. **No external logo assets.**
- **No `publications.json` schema change:** venue is derived (Books→Amazon,
  Papers→existing `badge`, Digital→Ko-fi).
- **Scope:** visuals only. The og:image / social-unfurl feature is a separate later cycle.

## Architecture

### Files

```
assets/site.css   ← replace .book-card/.pub-card/.store-card rule sets with the
                     .pubcard system (+ .pubcard-media, .pubcard-panel, .pubcard-body,
                     .pubcard-foot, .venue-badge, venue color modifiers).
build.js          ← collapse renderBookCard/renderPubCard/renderStoreCard into one
                     renderPublicationCard(item, type); renderPublications keeps the
                     three labeled buckets and calls it.
test/publications-data.test.js ← assert .pubcard + venue badge render per bucket.
data/publications.json ← unchanged (venue derived at render time).
index.html        ← regenerated by `node build.js` (no manual edit).
```

### Card anatomy

```
+----------------+--------------------------------+
|                | <h-title> serif title          |
|   media zone   | <secondary line>               |
|     (40%)      |                                 |
|  cover image   | (badge) Venue · meta        ↗  |  <- .pubcard-foot
|  OR venue panel|                                 |
+----------------+--------------------------------+
```

- `.pubcard` — `<a>`, horizontal flex, rounded, border, hover lift (reuse existing card
  hover treatment: shadow + translateY(-2px) + accent border).
- `.pubcard-media` — `flex: 0 0 40%`, with `min-width` and `max-width` so the 40% cannot
  get unreasonably large or small; `align-self: stretch`.
  - Books / Digital: `<img class="pubcard-cover">` (`object-fit: cover`).
  - Papers: `<div class="pubcard-panel">` — tinted background (accent-bg / blue-bg via
    variable), large venue wordmark (`arXiv` / `SSRN`) + category text.
- `.pubcard-body` — `flex: 1`, padding, column layout in this order: title → secondary
  line → **`desc` paragraph (books & digital only; papers omit it)** → `.pubcard-foot`.
  `.pubcard-foot` is pinned to the bottom via `margin-top: auto`.
- `.pubcard-foot` — flex row: `.venue-badge` (text wordmark chip) + `·` + meta, then an
  `↗` for external links.

### Per-type content mapping

| Type | media | title | secondary line | foot meta |
|------|-------|-------|----------------|-----------|
| Book | cover image | `title` | `subtitle` · `author` | venue=Amazon · `meta` (e.g. "Kindle · 134p") |
| Paper | venue panel (badge+cat) | `title` | authors (self bolded) | venue=`badge` · formatted `date` |
| Digital | thumbnail image | `title` | `desc` | venue=Ko-fi |

(Description text: books/digital keep their `desc`; for papers the authors line stands in
as the secondary line, matching today.)

### Venue badge

- `.venue-badge` — a small text pill (mono font, the venue name as its content), styled
  like the site's existing `.pub-badge`/`.store-badge`, colored by a venue modifier
  class. No monogram, no circle — the chip text IS the venue name, so nothing repeats.
- Venue text: `arXiv`, `SSRN`, `Ko-fi`, `Amazon`.
- Venue color modifiers (all via existing CSS variables):
  - `.venue-arxiv` → red family (`--red*`), `.venue-ssrn` → blue family (`--blue*`),
    `.venue-kofi` → accent (`--accent*`), `.venue-amazon` → accent (`--accent*`).

### Render interface (build.js)

- `venueFor(type, item) -> { key, label }` — derives venue (`label` is the chip text).
  - `type==='books'` → `{ key:'amazon', label:'Amazon' }`
  - `type==='papers'` → from `item.badge`: `arXiv` → `{key:'arxiv',label:'arXiv'}`, `SSRN` → `{key:'ssrn',label:'SSRN'}`
  - `type==='digital'` → `{ key:'kofi', label:'Ko-fi' }`
- `renderPublicationCard(item, type) -> string` — emits the `.pubcard` markup for the
  given bucket type, choosing image vs panel and the correct secondary line + foot.
- `renderPublications(pubs)` — unchanged contract: three `.pub-bucket-label` buckets,
  each mapping its items through `renderPublicationCard(item, type)`.

### Responsive

- Desktop: 40:60 horizontal split, stacked full-width within each bucket.
- ≤ 640px: `.pubcard` switches to `flex-direction: column` — media on top (fixed
  aspect height), content below. `.pubcard-media` `flex-basis` resets to auto.

## Testing

- `test/publications-data.test.js` updated:
  - `renderPublications(pubs)` contains the three bucket labels (unchanged).
  - Output contains `class="pubcard"` for each item; count of `.pubcard` ==
    books+papers+digital.
  - A book card emits `pubcard-cover` (img) + `venue-amazon`; a paper emits
    `pubcard-panel` + `venue-arxiv`; a Ko-fi card emits `pubcard-cover` + `venue-kofi`.
- Existing suite stays green; `node build.js` remains idempotent and the article-list
  equivalence gate is untouched.

## Out of scope (YAGNI)

- og:image / social-unfurl generation (separate later cycle; may reuse a generator).
- Real brand logo SVGs (using CSS text wordmark chips now).
- Changing `publications.json` structure.
- Grid (2-up) layout — stacked full-width for now; revisit only if a bucket grows.
- Restyling the homepage article rows or any article page.

## Success criteria

- All Publications render as one consistent `.pubcard`; papers no longer look bare.
- Books/Digital show cover art at 40%; Papers show a tinted venue panel.
- Each card has a text venue wordmark chip (arXiv/SSRN/Ko-fi/Amazon) in its foot row.
- Light and dark modes both read correctly (colors via variables only).
- `node build.js` regenerates `index.html`; full test suite green; build idempotent.
