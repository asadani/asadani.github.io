Publications
arXiv cs.AI arXiv:2604.21816
Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP/Tools Tax in Scalable Agentic Workflows
Anuj Sadani, Deepak Kumar

Introduces Tool Attention — gated attention over tool schemas combined with a two-phase lazy loader that keeps compact summaries in context and promotes full schemas only when needed. On a simulated 120-tool, six-server benchmark, per-turn tool tokens drop 95% (47.3k → 2.4k) and effective context utilisation rises from 24% to 91%. The argument: protocol-level efficiency, not raw context length, is the binding constraint for scalable agentic systems.
