Field notes

Lessons from the move

  • Open a new terminal after installing Docker, Rust, Java or LaTeX. Their PATH changes only reach new shells.
  • macOS ships Python 3.9 for its own use. Install a current Python with Homebrew and give each project its own virtual environment, so nothing touches the system one.
  • npm 11 skips dependency install scripts. That is harmless for esbuild and fsevents, but puppeteer will not download its browser. Point it at Chrome instead.
  • BasicTeX is small on purpose. When a build says File 'x.sty' not found, run tlmgr search --global --file x.sty to find the package, then install it.
  • “Needs CUDA” usually means “written for NVIDIA”. Apple’s GPU (device mps) ran a 0.6B voice model faster than real time, while CPU mode did not finish. The code often hardcodes cuda and needs one line changed.
  • One failed download is not a failed script. A flaky DNS lookup for a package host looks like an error in your setup. Wait a minute and re-run.
  • oh-my-zsh’s installer renames your .zshrc. Pass KEEP_ZSHRC=yes, and write your config first so the file it keeps is the right one.
  • Guard every file write with [ -f file ] ||. A shared notes folder can gain files from another agent while you work, and a plain cat > will overwrite them.
