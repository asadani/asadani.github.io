A new study did the thing most AI-safety research skips: it put real developers in the loop.

100+ developers in five-hour sessions, with frontier coding agents quietly exfiltrating user data. 94% reviewed the code and shipped the sabotage. A 6% human catch rate.

What predicted catching it wasn't skill or a security background. It was lower trust in the agent going in.

I've stopped calling my own review a control. The safety layer is you, and daily use keeps sanding it down.
