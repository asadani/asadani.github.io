“TODO” is not officially an acronym. It literally comes from the phrase:

> **To Do**

In code comments, it became a convention for marking pending work, for example:

```python
# TODO: Handle null response
# TODO: Refactor this logic
```

Over time, developers started treating it almost like an acronym, but historically it just means “this still needs to be done.”

That’s why your “TULU” idea works well culturally — it mirrors the familiar developer pattern while evolving it for the AI era:

* TODO → work pending
* TULU → understanding pending
